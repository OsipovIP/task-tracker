## 🚀 Установка

### 1. Создание бота в Telegram

1. Откройте Telegram и найдите [@BotFather](https://t.me/botfather)
2. Отправьте команду `/newbot`
3. Введите имя бота (например: "Task Tracker Bot")
4. Введите username бота (должен заканчиваться на `bot`, например: `task_tracker_bot`)
5. Скопируйте токен, который выдаст BotFather

### 2. Установка зависимостей

```bash
cd /home/kiptest/task/task_tracker_project
docker exec django_task_tracker pip install python-telegram-bot==20.7
```

### 3. Добавление токена в .env

Отредактируйте файл `.env` и добавьте:

```bash
TELEGRAM_BOT_TOKEN=your_bot_token_here
```

### 4. Запуск бота

#### Вариант А: В отдельном контейнере (рекомендуется)

Создайте `Dockerfile.bot`:

```dockerfile
FROM python:3.11-slim

WORKDIR /app

COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

COPY . .

CMD ["python", "telegram_bot/bot.py"]
```

Добавьте в `docker-compose.yml`:

```yaml
  telegram_bot:
    build:
      context: .
      dockerfile: Dockerfile.bot
    container_name: task_tracker_bot
    env_file:
      - .env
    depends_on:
      - db
      - app
    restart: unless-stopped
```

Запустите:

```bash
docker-compose up -d telegram_bot
```

#### Вариант Б: В существующем контейнере

```bash
docker exec -d django_task_tracker python telegram_bot/bot.py
```

#### Вариант В: На хосте

```bash
cd /home/kiptest/task/task_tracker_project
export DJANGO_SETTINGS_MODULE=task_tracker_project.settings
export TELEGRAM_BOT_TOKEN=your_token_here
python telegram_bot/bot.py
```

## 📱 Использование бота

### Первый запуск

1. Найдите своего бота в Telegram по username
2. Нажмите `Start` или отправьте `/start`
3. Авторизуйтесь:
   ```
   /login username password
   ```

### Доступные команды

| Команда | Описание |
|---------|----------|
| `/start` | Начало работы с ботом |
| `/help` | Справка по командам |
| `/login <username> <password>` | Авторизация |
| `/tasks` | Список моих задач |
| `/checking` | Задачи на проверке (для менеджеров) |

### Работа с задачами

#### Просмотр задач
```
/tasks
```

Вы получите список задач с кнопками:
- 👁️ **Подробнее** - показать детальную информацию
- ✅ **Закрыть** - закрыть задачу с отчетом

#### Закрытие задачи

1. Нажмите кнопку **✅ Закрыть** под задачей
2. Отправьте описание выполненной работы (текстом)
3. Задача автоматически перейдет в статус "Проверка"

#### Проверка задач (для менеджеров)

```
/checking
```

Вы получите список задач на проверке с кнопками:
- 👁️ **Подробнее** - детали задачи
- ✅ **Подтвердить** - перевести в "Выполнено"
- 🔄 **Вернуть** - вернуть в работу

## 🔐 Безопасность

⚠️ **ВАЖНО:**
- Пароли передаются в открытом виде через /login
- Рекомендуется использовать отдельные пароли для Telegram
- Или реализовать OAuth/Token авторизацию

### Улучшение безопасности (опционально)

Вместо `/login username password` можно создать систему с одноразовыми токенами:

1. Пользователь генерирует токен на веб-сайте
2. Отправляет токен боту: `/token ABC123`
3. Бот привязывает Telegram ID к аккаунту

## ❓ Проблемы и решения

### Бот не отвечает

1. Проверьте, что токен правильный
2. Проверьте, что бот запущен
3. Проверьте логи

### Ошибка авторизации

1. Проверьте правильность username/password
2. Проверьте подключение к базе данных

### Задачи не отображаются

1. Проверьте, что пользователь авторизован
2. Проверьте, что у пользователя есть задачи в системе
