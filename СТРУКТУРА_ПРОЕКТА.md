## 🔧 Основные файлы и их функции

### Настройки проекта:
- **`settings.py`** — конфигурация Django, БД, шаблоны
- **`docker-compose.yml`** — настройки контейнеров, порты, тома
- **`requirements.txt`** — зависимости Python

### Модели данных (`models.py`):
- **`Task`** — основная модель задач с интеграцией ITIL
- **`OesCategory`** → **`OesModel`** → **`OesObject`** — иерархия оборудования
- **`TaskComment`** — комментарии к задачам
- **`TaskPhoto`** — фотографии задач
- **`FaultCategory`** — категории неисправностей для отчетов
- **`TaskCompletionReport`** — отчеты о закрытии задач

### Контроллеры (`views.py`):
- **`task_list`** — список задач (Мои задачи)
- **`task_pool`** — пул задач (к выполнению)
- **`all_tasks`** — все задачи с фильтрацией по статусу
- **`task_create`** — создание задачи
- **`task_detail`** — детали задачи с редактированием
- **`task_claim`** — захват задачи из пула
- **`task_confirm_receipt`** — подтверждение получения задачи
- **`ajax_load_objects`** — AJAX загрузка объектов для автокомплита

### Формы (`forms.py`):
- **`TaskForm`** — форма создания с автокомплитом активов
- **`TaskEditForm`** — форма редактирования задач (для менеджеров)
- **`TaskStatusForm`** — изменение статуса
- **`TaskCommentForm`** — добавление комментария
- **`TaskPhotoForm`** — загрузка фотографий
- **`TaskCompletionReportForm`** — отчет о закрытии задачи

### Админка (`admin.py`):
- **`TaskAdmin`** — управление задачами с интеграцией ITIL
- **`OesObjectAdmin`** — справочник объектов с импортом из API
- **`OesModelAdmin`** — справочник моделей
- **`OesCategoryAdmin`** — справочник категорий
- **`FaultCategoryAdmin`** — управление категориями неисправностей
- **`TaskCompletionReportAdmin`** — просмотр отчетов о закрытии
- **`TaskCommentAdmin`** — управление комментариями
- **`TaskPhotoAdmin`** — управление фотографиями

### Шаблоны:

#### 🏗️ Базовый шаблон:
- **`base.html`** — основа всех страниц
  - Навигационная панель с логотипом "Task Tracker"
  - Приветствие пользователя и кнопка выхода
  - Подключение Bootstrap 5.3.3
  - Блоки для расширения: `title`, `content`, `extra_head`, `extra_js`

#### 📋 Основные страницы:
- **`tasks/task_list.html`** — список задач
  - Карточки задач в адаптивной сетке (1-3 колонки)
  - Отображение: ID, заголовок, приоритет, статус, назначение, срок
  - Кнопки "Взять задачу" для задач из пула
  - Счетчик общего количества задач
  - Сообщения Django (success/error/warning)

- **`tasks/task_detail.html`** — детали задачи
  - **Левая колонка:** основная информация, описание, фотографии, комментарии
  - **Правая колонка:** действия (статус, загрузка фото, подтверждение)
  - Форма добавления комментариев
  - Галерея фотографий с превью
  - Форма изменения статуса (только для исполнителя)
  - Подтверждение получения задачи (ACK)

- **`task_form.html`** — форма создания задачи
  - Двухэтапный выбор: модель → объект
  - Select2 для красивого интерфейса
  - AJAX загрузка объектов по выбранной модели
  - jQuery для динамического обновления полей

#### 🔐 Аутентификация:
- **`registration/login.html`** — страница входа
  - Центрированная форма авторизации
  - Обработка ошибок входа
  - Bootstrap стилизация
  - Интеграция с Django Auth

#### 🛠️ Технические особенности шаблонов:
- **Bootstrap 5.3.3** — современная адаптивная верстка
- **Font Awesome** — иконки для кнопок и элементов
- **Select2** — улучшенные выпадающие списки с поиском
- **jQuery** — AJAX взаимодействие и динамика
- **Карточный интерфейс** — современный дизайн с тенями
- **Адаптивность** — корректное отображение на всех устройствах
- **Цветовая схема** — приоритеты (красный=критический, оранжевый=высокий)
- **Условная логика** — разный контент для разных ролей пользователей

### Утилиты:

## 🗄️ Структура базы данных

### Основные таблицы:

#### 📋 **tasks_task** — Основная таблица задач
| Поле | Тип | Описание |
|------|-----|----------|
| `id` | Serial (PK) | Уникальный ID задачи |
| `title` | Varchar(255) | Заголовок задачи |
| `description` | Text | Подробное описание |
| `reporter_id` | FK → auth_user | Создатель задачи (nullable) |
| `assigned_to_id` | FK → auth_user | Исполнитель (nullable) |
| `assigned_group_id` | FK → auth_group | Группа исполнителей (nullable) |
| `status` | Varchar(20) | Статус: todo, in_progress, waiting, done |
| `priority` | Varchar(20) | Приоритет: critical, high, medium, low |
| `created_at` | Timestamp | Дата создания |
| `due_date` | Timestamp | Срок выполнения (nullable) |
| `acknowledged_at` | Timestamp | Подтверждение получения (nullable) |
| `updated_at` | Timestamp | Дата последнего обновления |
| `oes_object_id` | FK → tasks_oesobject | Связанный актив (nullable) |
| `external_source` | Varchar(50) | Внешний источник (ITIL, Jira) (nullable) |
| `external_id` | Varchar(100) | ID во внешней системе (nullable) |
| `external_data` | JSON | Дополнительные данные из внешней системы (nullable) |

**Индексы:**
- Уникальное ограничение: `(external_source, external_id)` (только если оба не NULL)

#### 🏭 **tasks_oescategory** — Категории оборудования
| Поле | Тип | Описание |
|------|-----|----------|
| `id` | Serial (PK) | Уникальный ID |
| `source_id` | Integer (UNIQUE) | ID из внешнего источника |
| `name` | Varchar(255) | Название категории |

#### 🔧 **tasks_oesmodel** — Модели оборудования
| Поле | Тип | Описание |
|------|-----|----------|
| `id` | Serial (PK) | Уникальный ID |
| `source_id` | Integer (UNIQUE) | ID из внешнего источника |
| `category_id` | FK → tasks_oescategory | Категория |
| `name` | Varchar(255) | Название модели |

#### 🚛 **tasks_oesobject** — Конкретные объекты (единицы техники)
| Поле | Тип | Описание |
|------|-----|----------|
| `id` | Serial (PK) | Уникальный ID |
| `source_id` | Integer (UNIQUE) | ID из внешнего источника (nullable) |
| `model_id` | FK → tasks_oesmodel | Модель (nullable) |
| `name` | Varchar(255) | Название объекта (например, "0029") |

#### 📱 **tasks_oesobjectdevice** — Устройства объектов
| Поле | Тип | Описание |

| `source_id` | Integer (UNIQUE) | ID из внешнего источника (nullable) |
| `oes_object_id` | FK → tasks_oesobject | Объект (nullable) |

#### 💬 **tasks_taskcomment** — Комментарии к задачам
| Поле | Тип | Описание |

#### 📸 **tasks_taskphoto** — Фотографии задач
| Поле | Тип | Описание |
|------|-----|----------|

| `task_id` | FK → tasks_task | Задача |
| `image` | ImageField | Файл изображения |
| `uploaded_by_id` | FK → auth_user | Кто загрузил |
| `uploaded_at` | Timestamp | Дата загрузки |

#### 🔧 **tasks_faultcategory** — Категории неисправностей
| Поле | Тип | Описание |
|------|-----|----------|
| `id` | Serial (PK) | Уникальный ID |
| `name` | Varchar(100) | Название категории |
| `description` | Text | Описание (nullable) |
| `is_active` | Boolean | Активна ли категория |
| `sort_order` | Integer | Порядок сортировки |

#### 📊 **tasks_taskcompletionreport** — Отчеты о закрытии задач
| Поле | Тип | Описание |
|------|-----|----------|
| `id` | Serial (PK) | Уникальный ID |
| `task_id` | FK → tasks_task (UNIQUE) | Задача (один отчет на задачу) |
| `completed_by_id` | FK → auth_user | Исполнитель |
| `fault_category_id` | FK → tasks_faultcategory | Категория неисправности (nullable) |
| `work_performed` | Text | Выполненная работа |
| `root_cause` | Text | Корневая причина (nullable) |
| `preventive_measures` | Text | Предупредительные меры (nullable) |
| `time_spent` | Duration | Затраченное время (nullable) |
| `created_at` | Timestamp | Дата создания отчета |

## 🚀 Новые функции

### ITIL Интеграция:
- **Автоматический импорт** инцидентов из ITIL системы
- **Преобразование** ITIL инцидентов в полноценные задачи
- **Предотвращение дублирования** через уникальные ограничения
- **Сохранение исходных данных** в JSON формате

### Система отчетности:
- **Категории неисправностей** для структурирования отчетов
- **Обязательные отчеты** при закрытии задач

## 🔧 Команды управления

### Работа с данными:
```bash
# Синхронизация ITIL
docker exec django_task_tracker python manage.py sync_itil_incidents \
  --username osipovip --password HOW45h05 \
  --service-filter "Поддержка УАПП"

docker exec django_task_tracker python manage.py import_oes_objects

# Создание категорий неисправностей
docker exec django_task_tracker python manage.py shell -c "
from tasks.models import FaultCategory
categories = [
    ('Аппаратная неисправность', 'Проблемы с оборудованием'),
    ('Программная ошибка', 'Ошибки в ПО'),
    ('Настройка/Конфигурация', 'Проблемы с настройками'),
    ('Сетевая проблема', 'Проблемы с сетью'),
    ('Пользовательская ошибка', 'Неправильные действия пользователя'),
    ('Плановое обслуживание', 'Профилактические работы'),
    ('Установка/Обновление', 'Установка ПО, обновления'),
    ('Консультация/Обучение', 'Консультации, обучение'),
    ('Другое', 'Прочие вопросы')
]
for i, (name, desc) in enumerate(categories, 1):
    FaultCategory.objects.create(name=name, description=desc, sort_order=i, is_active=True)
"
```
